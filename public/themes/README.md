# Drop-in themes

Themes are **not** part of the PicoCrank Vite/JS CSS bundle. Drop a folder here and restart the dev server (or rebuild) to make it discoverable.

## Layout

```
public/themes/
├── index.json              # generated by Vite — do not edit by hand
├── <theme-folder-name>/
│   ├── theme.css           # required
│   └── …optional assets…
```

A directory is a valid theme only if it contains `theme.css`.

## Asset URLs

Theme CSS is loaded via `@import` into a document-level stylesheet, so relative URLs resolve incorrectly. Use absolute paths:

```css
body {
  background-image: url('/themes/mytheme/background.png');
}
```

## Switching

The examples app uses `useCustomTheme()` to list themes from `index.json` and apply the selected `theme.css` with `@import … layer(theme)`.
